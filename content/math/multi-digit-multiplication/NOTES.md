# 教学偏好与维护说明

- 请求：`/teach 多位数乘多位数学习,页面里面要制作一个教学视频,给小朋友看的 卡通有趣`；随后用户要求“直接自动完成所有课时的内容”。本次一次性完成三课，使用项目默认三年级画像，不假定已掌握任何一课。
- 视频的实现假设：“教学视频”做成页面内由 SVG + JavaScript 实时绘制的卡通动画（小松鼠果果），具备播放/暂停、可拖动进度、章节、上一幕/下一幕、慢速、常驻字幕、文字稿和中途暂停预测题。没有提交 MP4：动画可由同一份源码再生成，且离线、可访问、可编辑。若需要可下载的视频文件，可用无头 Chrome 录制该动画并用 ffmpeg 编码，作为构建产物另行处理，不进 Git。
- 朗读旁白只使用本机离线中文语音（`localService`），不把文字发给联网语音服务；设备没有离线中文语音时按钮禁用，以字幕为主。视频不自动播放；系统开启“减少动态效果”时舞台不播放动画、画面直接切换。
- 视频组件：`assets/cartoon-video.js` + `assets/cartoon-video.css`。时间线唯一来源是页面里的文字稿列表 `[data-video-shots] > li`（`data-shot`、`data-duration`、可选 `data-chapter`、`data-pose`、`data-prompt`）；舞台元素用 `data-from` / `data-until` / `data-delay` / `data-focus` 控制出现时机。会移动的图层不能带 `transform` 属性，把定位放在子元素上。角色和道具（松鼠、筐、麻袋、小火车车厢、松果）由组件生成，课时只写摆放位置。课时专属的编排样式写在该课 `<head>` 的 `<style>` 中。
- 暂停预测题复用 `lesson.js` 的 `data-quiz` 契约，答对后才出现“继续播放”；它计入活动进度，不计入掌握证据。
- 样式：`assets/course.css` 导入括号单元的课程样式（其又导入幂单元样式），再加本单元主题与竖式组件 `.vcalc`；通用测验/进度/打印复用幂单元的 `assets/lesson.js`。所有依赖都是仓库相对路径，无外部脚本、字体、请求或遥测。
- 进位写法全单元统一：进位小数字写在它要加进去的那一位的右上角（同一行、同一列），用完划掉。第 2 课最初把两次进位都记在被乘数“3”上方，第二行的进位因此落在十位一列、与要加进去的百位不在同一列；2026-10-09 经用户确认改为本写法，与第 3 课一致。
- 竖式第二行一律写成“末位对齐十位”，省略的 0 只在讲解中用虚线框提示。颜色只作辅助，每行右侧都有文字说明这一行算的是什么。
- 进度键：`knowtrail:multiply-0001:v1:progress`，第二、三课类推。仅记录活动完成标记，不保存姓名、原始作答或时间。改变检查题或判定含义时递增 HTML 的 `data-lesson-version`。
- 每份打印材料为学习页（含视频分镜）、练习页、独立检查页（C 区）、答案页，A4 黑白；不设姓名栏。纸面题目与网页题目不同。
- 使用方法：用浏览器打开 `lessons/0001-two-digit-no-carry.html`，或从站点首页进入；保留整个仓库目录以确保共享资源的相对路径有效。
- 课程预先编写不表示学习完成；收到真实学习证据后再创建 `learning-records/`。

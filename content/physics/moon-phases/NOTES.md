# 教学偏好与维护说明

- 请求：`/teach 月相`；编写过程中用户追加“每个课程页面里面都加一个视频讲解”。按项目记忆一次完成三课、三份纸笔版和速查卡，使用默认三年级画像，不假定已掌握任何一课。
- 学科归属：月相成因是“光照 + 观察位置”的几何模型，归入 `content/physics/`，并打天文、地球与宇宙标签。若以后建立“科学 / 天文”目录，可整体 `git mv`。
- 视频：沿用多位数乘法单元的页面内动画组件 `../../../math/multi-digit-multiplication/assets/cartoon-video.js`（时间线唯一来源是 `[data-video-shots] > li`，契约见该文件开头）。本单元角色是猫头鹰“咕咕”，夜里观察月亮，比松鼠更贴合主题；角色和道具在 `assets/moon-model.js` 的 `window.KnowtrailVideoCast` 中注册（`owl`、`moon`（`data-label` 为月相角度）、`moon-top`、`sun`、`earth`（`data-label="night"` 画出夜半球）、`flashlight`、`ball`、`calendar`、`star`、`cloud`）。为此给 `cartoon-video.js` 加了向后兼容的扩展点：内置角色找不到时再查 `window.KnowtrailVideoCast`。猫头鹰动作沿用 `data-pose` 的 `wave / point / think / surprised / cheer`，样式在 `assets/course.css`。
- 脚本顺序（都用 `defer`）：`lesson.js` → `moon-model.js` → `cartoon-video.js`。`moon-model.js` 必须在视频组件之前注册角色。
- 月相图：`<span class="moon-icon" data-moon="角度"></span>`，角度为新月后的度数（0 新月、45 蛾眉月、90 上弦月、135 凸月、180 满月、225 凸月、270 下弦月、315 残月）。画的是北半球、月亮高挂南边天空时的样子；朗读名称是形状描述（如“右边亮着弯弯的一条”），不直接说出月相名，避免替孩子答题。可用 `data-moon-label` 覆盖。
- 互动模型（契约见各课标记）：`[data-sequence-game]` 月相接龙（第一课）、`[data-orbit-lab]` 俯视轨道模拟器（第二课，需找到新月、上弦月、满月、下弦月才能完成）、`[data-sky-lab]` 天空时钟（第三课，傍晚 6 点和清晨 6 点共查过 4 次以上才能完成）、`[data-tonight]` 今晚的月亮。完成按钮复用 `lesson.js` 的 `[data-complete-checkpoint]`，初始禁用，条件满足后由 `moon-model.js` 启用。
- 农历日估算：Meeus 真朔公式，按北京时间判定初一。“今晚的月亮”的图和名称按今晚 8 点的实际日月角距（`elongationAt`）计算，主月相 ±12° 内说“接近××”，不查农历日表：2026 年九月上弦在初十、满月在十七，查表会和天上对不上。两者都已用 USNO 数据核验（见 RESOURCES.md）。只用设备本地日期计算，不联网；页面上写“大约”“以日历为准”。
- 农历日期与月相名称的对应表在 `moon-model.js` 的 `PHASES` 中，与 `unit.md` 的共享事实表一致；修改时两处同步。轨道模拟器、天空时钟和月相接龙用的是这张教学表和平均月龄。
- 分层：课标只列新月、上弦月、满月、下弦月，这四个“一定要会”，蛾眉月、凸月、残月“认得出就行”。计分题（练习、独立检查、纸笔 C 区）只用落在区间中间的农历日期，避开初二、初七、初九、初十、十四、十七、廿二、廿四、廿九、三十。
- 推荐观看：第一、三课用智慧教育平台“月相变化的规律”同步课（教科版三下旧版），第二课用“月有阴晴圆缺”（大象版四下）；链接未实际播放，可能需要登录。
- 掌握题的下拉框：给 `lesson.js` 的掌握表单加了 `select[data-correct]` 支持（原来只认 `input`），让三年级孩子不用打字也能作答月相名称。
- 样式：`assets/course.css` 导入括号单元的课程样式（其又导入幂单元样式）和视频播放器样式，再加夜空主题、月相图、互动模型、猫头鹰动作和打印规则。所有依赖都是仓库相对路径，无外部脚本、字体、请求或遥测。
- 安全：夜间观察须成人陪同；白天找月亮时绝不直视太阳，墨镜也不行；居家模型只用 LED 手电筒，不照眼睛，暗房间先清理地面、成人在场；有替代方案（网页模型）。
- 进度键：`knowtrail:moon-0001:v1:progress`，第二、三课类推。仅记录活动完成标记，不保存姓名、原始作答或时间。改变检查题或判定含义时递增 HTML 的 `data-lesson-version`。
- 每份打印材料为学习页（含视频分镜）、练习页、独立检查页（C 区）、答案页，A4 黑白；不设姓名栏。纸面题目与网页题目不同。月相图在打印时由同一脚本绘制，打印前请在浏览器中打开页面。
- 课程预先编写不表示学习完成；收到真实学习证据后再创建 `learning-records/`。
